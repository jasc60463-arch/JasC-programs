The program require python3.12

To download the program : click <> Code -> Download ZIP -> Extract file in your pc

Modules needed to be installed:


kivy

pip install kivy


pyautogui

pip install pyautogui


keyboard

pip install keyboard


plyer

pip install plyer


pyvda

pip install pyvda


AppOpener

pip install AppOpener


cv2

pip install opencv-python




mediapipe (it require a specific version)

pip install mediapipe==0.10.21
